# Meeting Minutes / Besprechungsprotokolle

One file per meeting, named `YYYY-MM-DD-topic.md` (e.g. `2026-09-19-kickoff.md`).
Language: German.

## Suggested structure per file

```markdown
# <Topic> — <YYYY-MM-DD>

## Attendees
- Name (role)

## Agenda / Notes
- ...

## Decisions
- ...

## Action Items
- [ ] Task — owner — due date (optional: issue reference)
```

Supervision/hours tracking lives separately in `../Betreuung.md`.
